## 💻 Requirements (Requisitos)

No se requiere experiencia previa en inglés. Solo necesitas:
1. Una computadora (Windows, macOS o Linux).
2. Conexión a internet.
3. [Visual Studio Code](https://code.visualstudio.com/) instalado.
4. [Python 3.8+](https://www.python.org/) instalado.
5. [Git](https://git-scm.com/) instalado.

---

## 🛠️ Setup & Installation (Configuración desde Cero)

### 1. Instalar Visual Studio Code y Python
- Descarga e instala **VS Code**.
- Descarga e instala **Python** (⚠️ Marca la casilla *"Add Python to PATH"* durante la instalación en Windows).

### 2. Clonar el Repositorio
Abre tu terminal y ejecuta:

```bash
git clone [https://github.com/DiegoDev21/60-days-technical-english.git](https://github.com/DiegoDev21/60-days-technical-english.git)
cd 60-days-technical-english
